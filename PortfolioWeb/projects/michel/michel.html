Michel's Story

Use W, A, S, and D to move Michel.

What ?

A 2D RPG game in Java where the player explores interconnected rooms filled with items and enemies. Goal of the game: Navigate through the dungeon, collect useful items, defeat creatures, and ultimately find the key that unlocks access to the final boss. The game is built around exploration, progression, and preparation before the ultimate confrontation.

How ?

Java programming project by team of 2 Implemented inheritance-based actors (players, enemies, saviors, projectiles) using object-oriented design. Created gameplay mechanics including health management, random map generation and an animated player. Designed interaction logic between entities (collisions, pickups, damage, healing).
