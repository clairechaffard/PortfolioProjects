Javions

Pratique de la programmation orientée-objet

What ?

Implemented a real time a flight tracking system designed to receive and decode live ADS-B signals emitted by aircraft. The system allows users to monitor nearby air traffic by visualizing aircraft positions on a dynamic interactive map. Interactive map navigation: mouse zoom in / zoom out, click on individual aircraft to display detailed flight information (altitude, speed, identification, position…)

How ?

Java / Object-Oriented Development: Built a Java-based interface using JavaFX. Developed and tested modular components using JUnit. Designed the user interface and implemented interactive feature Applied core OOP principles and design patterns to structure the reception, decoding, and visualization pipelines. Signal Processing & System Design: Learned and implemented low-level radio workflow: Signal sampling, ADS-B message extraction and Data decoding and visualization
