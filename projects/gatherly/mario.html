Gatherly

Software Entreprise - Bachelor's Project

What ?

Android application featuring unique user profiles and secure authentication. Collaboration platform allowing users to invite friends and created shared groups. Shared productivity tools including collaborative events and group-to-do lists. Geospatial visualization of activities via an integrated map interface. Gamified focus timer with points system, progress tracking, and friendly competitions. Notifications and achieevements badges to track personal activities

How ?

Backend integration using Firebase Firestore for cloud storage, authentication and real-time data synchronization. Modern UI development built with Jetpack Compose, adhering to UI/UX design best practices. Collaboration within a scrum team of 7, utilizing GitHub workflows, peer code reviews and sprint planning. ​
